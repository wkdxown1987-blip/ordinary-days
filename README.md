# Ordinary Days

개인 블로그. `posts.json`을 수정하면 게시글이 바뀝니다.

## 글 추가하기

`posts.json` 배열 안에 새 객체를 추가하세요. `id`는 다른 글과 겹치지 않아야 합니다. `date`는 `YYYY-MM-DD` 형식입니다. `content`에는 줄바꿈을 `\n`으로 넣을 수 있습니다. `image`는 이미지 URL이나 저장소에 업로드한 이미지의 상대 경로(예: `images/photo.jpg`)를 입력하세요.

GitHub Pages는 정적 호스팅이므로 블로그 화면 자체에서 글을 저장하지는 않습니다. GitHub에서 `posts.json`을 편집하고 커밋하면 반영됩니다.
